# 03 · Planning

**Methodology:** lightweight Agile (Kanban + short iterations), trunk-based development with GitHub Flow.

## Work breakdown
1. Engine: loop, input, physics, collisions
2. Content: 12 SDLC worlds (lessons, summaries, themes)
3. Level generator + tests
4. UI: title, world map, lesson cards, summaries, ending
5. Audio, touch controls, persistence
6. CI/CD + Pages deployment
7. Profile integration (banner + README)
8. Documentation

## Roadmap
| Milestone | Scope | Status |
|---|---|---|
| M1 Walking skeleton | Canvas, player, tiles | ✅ |
| M2 Playable level | Enemies, coins, blocks, flag | ✅ |
| M3 Full journey | 12 worlds + content | ✅ |
| M4 Polish | Sound, touch, saves | ✅ |
| M5 Ship | CI, Pages, profile link | ✅ |
| M6 Post-launch | Feedback, bug fixes, new features | 🔄 ongoing |

## Definition of Done
Code merged via PR · tests green · deployed · docs updated · manually smoke-tested.
